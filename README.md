# Raumplaner

Leichter Grundriss- und Möbelplaner in der Vogelperspektive, optimiert für Tablets.

## Nutzen
Seite in Chrome öffnen → Menü → „Zum Startbildschirm hinzufügen“. Danach startet der Planer wie eine App und funktioniert auch offline.

## Daten
- Jedes Gerät speichert seinen Stand lokal im Browser. Wer die Seite ohne Token öffnet, bekommt einen eigenen, leeren Planer und sieht keine fremden Daten.
- Optional: GitHub-Sync über das Wolken-Symbol oben rechts. Der Stand liegt dann als `daten.json` in einem **privaten** Repo und ist auf allen verbundenen Geräten gleich. Jede Änderung ist in der Versionsgeschichte des Repos nachvollziehbar.
- Zusätzliche Sicherung: Menü → „Als Datei exportieren“, z. B. nach OneDrive.

Dieses Repo enthält nur den Code, keine Raumdaten.
